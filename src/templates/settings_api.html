Decisions

The third question — how do I deal with it — in a form another tool can read. CrowdSec, nftables or a shell script can help themselves from here.

Vidar does not decide what is blocked. It says what somebody needs in order to decide. The selection travels with the answer, and every address carries its reason, because a feed whose membership rule is invisible is a blocklist — and a blocklist nobody can open is the thing this dashboard argues against.
